1. Trough COntroller project

Scope: UI Design • Front-End Development • Local Network Access

An interface layer developed for a single-unit tea trough system, designed to present live process conditions and enable structured control through a clear, centralized dashboard. The system supports both manual interaction and scheduled operation through predefined recipes.

The interface brings together multiple environmental and process inputs into one view—allowing operators to track drying conditions without needing to interpret scattered data points. Key readings such as dry bulb and wet bulb temperatures, moisture levels (current vs target), exhaust RH, and room conditions are continuously displayed alongside system status indicators.

Control within the interface is focused on operational elements like burner and fan management, as well as recipe-based scheduling. Operators can configure and run predefined drying cycles, monitor their progress in real time, and understand exactly what stage the system is in at any given moment.

The system is accessible across devices within a local network. Operators can log in via mobile or desktop to view or adjust the process without being tied to the physical control unit, ensuring flexibility in how the system is monitored and managed.

Key Highlights:

Unified dashboard for all critical drying parameters
Live comparison of current vs target moisture levels
Recipe-based scheduling with real-time progress tracking
Control over burner and fan systems
Local network access across mobile and desktop devices

2. Furnace Control System

Scope: UI Design • Front-End Development • Local Network Access

An interface system developed for a single-unit furnace, focused on structuring critical operational data and batch-based control into a clear, readable format. The system is designed to support continuous operation where multiple parameters need to be monitored and adjusted without ambiguity.

The interface consolidates core furnace data including current temperature, power settings, voltage, current, flame and fan status, along with cycle time, runtime, and batch information. All I/O states are visible within the system, giving operators a direct view of what is active at any given moment.

Control is centered around batch-based operation. Operators can configure and run predefined batches, reducing the need for repeated manual adjustments. The interface provides clear visibility into batch progress, system state, and active processes, ensuring that operators can track execution without constant intervention.

Safety-related conditions are reflected directly within the interface. Parameters such as maximum and safety temperature thresholds are structured to ensure that operational limits are always visible and logically constrained within the system.

The system is accessible over a local network, allowing monitoring and interaction through connected devices within the same environment. This extends the interface beyond the physical control unit while maintaining a closed, reliable network setup.

Key Highlights:

Consolidated view of furnace parameters and I/O states
Batch-based operation with real-time progress tracking
Visibility of critical values: temperature, power, voltage, current
Status indicators for flame, fan, and system activity
Integrated safety thresholds within operational limits
Local network access across connected devices

3. Multi zone sensor monitoring system

Scope: UI Design • Local Network Access

An interface designed to consolidate data from multiple sensors into a single, unified dashboard, organized by user-defined zones. The system allows different types of sensors to be grouped and monitored together, providing a structured overview of distributed inputs across a facility.

The interface focuses on clarity and flexibility—operators can view all connected sensors regardless of type, understand their current status, and navigate between zones without dealing with fragmented data sources. Each zone acts as a logical grouping, making it easier to interpret conditions across different areas.

Originally implemented for gas detection systems, the structure is adaptable to a wide range of sensor-based applications where centralized visibility is required.

The system is accessible over a local network, allowing users to monitor sensor data from connected devices within the same environment.

Key Highlights:

Unified dashboard for multi-sensor monitoring
Zone-based organization for structured visibility
Supports different sensor types within one system
Clear status overview across all zones
Local network accessibility across devices
