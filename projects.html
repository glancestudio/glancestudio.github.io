01 / Tea Processing

Trough COntroller

UI Design Front-End Development Local Network Access

An interface layer for a single-unit tea trough system — presenting live process conditions and enabling structured control through a clear, centralized dashboard. Supports both manual interaction and scheduled operation through predefined recipes.

Trough control dashboard — live process overview
Overview

The interface brings together multiple environmental and process inputs into one view — allowing operators to track drying conditions without needing to interpret scattered data points. Key readings such as dry bulb and wet bulb temperatures, moisture levels (current vs target), exhaust RH, and room conditions are continuously displayed alongside system status indicators.

Control is focused on operational elements like burner and fan management, as well as recipe-based scheduling. Operators can configure and run predefined drying cycles, monitor their progress in real time, and understand exactly what stage the system is in at any given moment. Accessible across devices within a local network — via mobile or desktop — without being tied to the physical control unit.

  • Unified dashboard for all critical drying parameters
  • Live comparison of current vs target moisture levels
  • Recipe-based scheduling with real-time progress tracking
  • Control over burner and fan systems
  • Local network access across mobile and desktop devices

02 / Furnace Control

Furnace COntrol
System

UI Design Front-End Development Local Network Access

An interface system for a single-unit furnace — structuring critical operational data and batch-based control into a clear, readable format. Designed for continuous operation where multiple parameters need to be monitored and adjusted without ambiguity.

Furnace control dashboard — operational overview
Overview

The interface consolidates core furnace data including current temperature, power settings, voltage, current, flame and fan status, along with cycle time, runtime, and batch information. All I/O states are visible within the system, giving operators a direct view of what is active at any given moment.

Control is centered around batch-based operation. Operators can configure and run predefined batches, reducing the need for repeated manual adjustments. Safety-related conditions — maximum and safety temperature thresholds — are structured to ensure operational limits are always visible and logically constrained. Accessible over a local network from connected devices within the same environment.

  • Consolidated view of furnace parameters and I/O states
  • Batch-based operation with real-time progress tracking
  • Visibility of critical values: temperature, power, voltage, current
  • Status indicators for flame, fan, and system activity
  • Integrated safety thresholds within operational limits
  • Local network access across connected devices

UI Design Local Network Access

An interface designed to consolidate data from multiple sensors into a single, unified dashboard — organized by user-defined zones. Different sensor types, grouped and monitored together, with a structured overview of distributed inputs across a facility.

03
Zone dashboard — multi-sensor unified view
Overview

The interface focuses on clarity and flexibility — operators can view all connected sensors regardless of type, understand their current status, and navigate between zones without dealing with fragmented data sources. Each zone acts as a logical grouping, making it easier to interpret conditions across different areas.

Originally implemented for gas detection systems, the structure is adaptable to a wide range of sensor-based applications where centralized visibility is required. Accessible over a local network from connected devices within the same environment.

  • Unified dashboard for multi-sensor monitoring
  • Zone-based organization for structured visibility
  • Supports different sensor types within one system
  • Clear status overview across all zones
  • Local network accessibility across devices
